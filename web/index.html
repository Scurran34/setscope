One-time setup: add the Rabbithole extension to Chrome

It reads the 1001Tracklists page you open, sends the set links here, and closes the tab. It only acts on tabs Rabbithole opens.
  1. Go to chrome://extensions and turn on Developer mode (top right).
  2. Click Load unpacked and choose the setscope/extension folder.
  3. Reload this page.

Update the Rabbithole extension

Chrome is still running an older copy (; this app needs ). Older copies can stop at the first ~15 sets on a page.
  1. Go to chrome://extensions.
  2. On the Rabbithole capture card, click the circular reload arrow. It should then say .
  3. Reload this page.
