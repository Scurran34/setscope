One-time setup: add the setscope extension to Chrome

It reads the 1001Tracklists page you open, sends the set links here, and closes the tab. It only acts on tabs setscope opens.
  1. Go to chrome://extensions and turn on Developer mode (top right).
  2. Click Load unpacked and choose the setscope/extension folder.
  3. Reload this page.

Fetching sets
8 seconds between requests to stay polite to 1001Tracklists. The report below updates as sets arrive.
